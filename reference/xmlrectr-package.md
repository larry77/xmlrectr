# xmlrectr: generic XML rectangling

Convert arbitrary XML into canonical node tables and analysis-friendly
rectangles with explicit profiles, bounded streaming, optional native
acceleration, and automatic record-level parallel execution.

## Details

The normal workflow is proposal, review, profile, compilation, and
rectangling. For exploratory work, the analyst layer provides a
self-contained single-table projection. See the package README and
vignettes for complete workflows.
