# Validate the canonical XML node-table contract

Work with the canonical XML-node representation that preserves node
identity, parentage, source order, namespaces, node types and scalar
values.

## Usage

``` r
validate_xml_nodes(nodes)
```

## Arguments

- nodes:

  A data frame intended to satisfy the canonical XML node-table
  contract.
