# Coerce a portable object to an XML profile

Discover structural evidence and define a reviewable, reusable
extraction contract. Proposals and XSD evidence are advisory rather than
silently executable.

## Usage

``` r
as_xml_profile(x)
```

## Arguments

- x:

  An existing `xml_profile` object or a compatible list-like profile
  representation.
